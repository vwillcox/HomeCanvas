Custom widgets

Widgets of your own, installed on the panel.

Installed


        
Widgets written in Dart are switched off. Switch them on at the panel: Settings → Dashboard → Widgets written in Dart.

  

  

    
Two kinds

        
Written in Dart (.dart) — as full as any widget the panel comes with: its own drawing, taps, timers, anything. The panel checks it, builds it into itself and restarts, which takes a few minutes. If it does not check, build or start, the panel stays on the build it had and what the compiler said is shown here, to fix and send again. Off until switched on at the panel: Settings → Dashboard → Widgets written in Dart. Download the Dart example

        
Described in JSON (.json) — what it is called, its settings, the address its data comes from and how to show it. On the panel at once, with no rebuild; it can show figures, cards and lists, and nothing more. Download the JSON example

        
Only install widgets you trust: one in Dart runs on the panel as a program; one in JSON tells the panel which address to fetch.
